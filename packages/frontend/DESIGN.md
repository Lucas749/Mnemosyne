# Mnemosyne Frontend — Design Spec

## Concept: Decentralized Wikipedia meets DeFi dashboard

The frontend has two modes users switch between:

1. **Knowledge Browser** (Wikipedia feel) — read-focused, see the collective brain
2. **Agent Demo** — interactive, add a fact and watch the agent recall it live

---

## Pages / Routes

### `/` — Knowledge Browser (default view)

Think Wikipedia's main page crossed with a DeFi explorer.

**Header bar:**
- Mnemosyne logo + tagline "The world's self-cleaning knowledge base"
- Global search bar (semantic search — queries the /query endpoint)
- "Submit Entry" CTA button (wallet-gated)
- Wallet connect button (ENS name shows when connected)
- Stats strip: Total entries | Total staked | Total royalties paid | Active validators

**Knowledge feed (main content):**
- Filterable grid/list of entries sorted by: Recent | Most Queried | Highest Stake | Contested
- Filter chips: All | Factual | Observations | Labeled Examples | Contested | Stale
- Each entry card shows:
  - Content preview (first 120 chars)
  - Domain badge (factual, observation, etc.)
  - Author ENS name + avatar (e.g. `contributor.mnemosyne.eth`)
  - Stake amount (e.g. "Ξ 0.05 staked")
  - Status badge: 🟡 Pending | 🟢 Active | 🔴 Contested | 🔵 Stale | ⚫ Burned
  - Query count (how many times retrieved)
  - Royalties earned
  - Time posted + challenge window countdown (if still pending)
  - Tags as pills
  - "Challenge" button (only if entry is active, requires wallet)

**Sidebar (right):**
- Live activity feed: recent submissions, challenges opened, slashes executed
- Top contributors leaderboard (by royalties earned)
- Top validators leaderboard (by accuracy rate + ENS tier)

---

### `/entry/[id]` — Entry Detail Page

Like a Wikipedia article page, but with economic history.

**Top section:**
- Full entry content (rendered as prose)
- Domain + tags
- Author: ENS name, link to their profile, their tier
- Submitted: timestamp
- Status: big colored badge

**Economic sidebar:**
- Stake: Ξ X.XX (locked in StakeVault)
- Query count: N times
- Royalties earned: Ξ X.XX
- Challenge window: opens/closes at (countdown)
- iNFT token ID + link to 0G explorer

**Challenge history section:**
- List of all challenges opened against this entry
- Each challenge: challenger ENS, stake, reason, status, resolution, who got slashed
- AI verdict from 0G Compute (TEE-attested) shown inline

**Challenge button:**
- Opens a modal: "Why is this wrong?" + evidence field + stake amount
- Signs and submits to ChallengeManager.sol

---

### `/submit` — Submit Entry

Clean form:
- Content textarea (the fact/observation/data)
- Domain selector (factual / observation / labeled_example / structured_data / correction)
- Tags input (comma-separated)
- Sources field (optional URLs)
- Stake amount (min 0.005 ETH, shows USD equivalent)
- ENS subname claim: if user doesn't have `X.mnemosyne.eth` yet, prompt to claim one
- Preview card showing how the entry will look in the browser
- Submit button → signs tx → shows success with entry ID + link to 0G explorer

---

### `/brain` — The Brain

A visual representation of the entire knowledge base. Think a semantic map.

**Two views toggled:**

1. **List view** (default) — all entries sorted by embedding cluster
   - Group by topic (using embedding similarity to cluster)
   - Show topic cluster names auto-generated by the model
   - Within each cluster, entries sorted by stake

2. **Graph view** — force-directed graph
   - Each node is an entry
   - Edges between semantically similar entries (cosine similarity > 0.7)
   - Node size = stake amount
   - Node color = domain type
   - Hover to see entry preview
   - Click to open entry detail

**Ask the brain:**
- Chat input at the top: "What does this knowledge base know about X?"
- Calls POST /query → highlights matching nodes in graph view
- Shows retrieved entries ranked by similarity with confidence scores
- This is the live demo of the RAG pipeline

---

### `/demo` — Live Demo (Hackathon Showpiece)

A two-panel, side-by-side interactive demo:

**Left panel: Knowledge Base**
- Submit a new fact (pre-filled with a compelling example)
- "Add to brain" button
- Watch the entry appear in the list in real time

**Right panel: Agent Chat**
- A live chat interface powered by the Mnemosyne memory API
- Before you add the fact: ask the agent → it says "I don't have that information"
- After you add the fact: ask again → agent recalls it instantly from Mnemosyne
- Shows the raw memory retrieval (similarity score, storage ref) in a collapsed debug panel
- This is the "aha moment" that proves the system works

**Demo script (pre-loaded as example):**
1. Fact to add: "The Ethereum merge happened on September 15, 2022, transitioning from PoW to PoS at epoch 144896."
2. Question to ask: "When did Ethereum switch to proof of stake?"
3. Before adding: agent answers from its base knowledge (fuzzy)
4. After adding: agent answers with "According to my Mnemosyne memory (confidence: 0.94): The Ethereum merge happened on September 15, 2022..."

---

### `/profile/[ens]` — Contributor / Validator Profile

- ENS name + avatar
- Role: Contributor | Validator | Both
- Stats: entries submitted, total staked, royalties earned, accuracy rate (validators)
- Their entries (paginated)
- Their challenge history
- ENS text records displayed (memory.index, payment.token, tier, etc.)

## Design system

**Colors:**
- Background: `#0a0a0a` (near-black)
- Surface: `#111111`
- Border: `#222222`
- Text primary: `#f0f0f0`
- Text secondary: `#888888`
- Accent (active/green): `#00d084`
- Warning (contested/yellow): `#f59e0b`
- Danger (burned/slashed): `#ef4444`
- ENS purple: `#6366f1`

**Typography:**
- Headers: Inter or Geist Sans — clean, modern
- Entry content: Serif (Georgia or Lora) — Wikipedia-like readability
- Code/addresses: Geist Mono

**Status colors:**
- 🟡 Pending: `#f59e0b` (amber)
- 🟢 Active: `#00d084` (green)
- 🔴 Contested: `#ef4444` (red)
- 🔵 Stale: `#6366f1` (indigo)
- ⚫ Burned: `#666666` (gray)

---

## Key interactions

- **Challenge flow**: Connect wallet → click Challenge → modal opens → enter reason + stake → sign tx → live update
- **Submit flow**: Connect wallet → fill form → preview entry → sign tx → entry appears in browser
- **Brain search**: Type query → entries highlight in graph → ranked list appears below
- **Demo flow**: Add fact → ask agent → see memory recall with confidence score

---

## Data sources

All data comes from:
1. `packages/api` REST endpoints (`/query`, `/store`, `/load-manifest`, `/health`)
2. On-chain reads via `viem` (entry status, stakes, challenge history from contracts)
3. 0G Storage for full entry content and embeddings
4. ENS for contributor/validator text records
